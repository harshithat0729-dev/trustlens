# MVP scope (freeze on Day 2)

## In scope
- Link / URL check (structure, lookalike domains, source match)
- Message check (fee, urgency, impersonation, payment channel)
- Image check (metadata + OCR -> message checks)
- Claim check (heuristics + source match)

## Out of scope (later)
- Automatic monitoring of calls / WhatsApp / Google results
- Live reputation / fact-check APIs (reported as unavailable for now)
- Production forensic deepfake detection (trial on Day 15, decide then)
- Audio (only if time remains)

## Hard rules
- Never claim 100% real/fake
- Always show evidence + limitations + safe next steps
- Report a check as unavailable rather than inventing a result
